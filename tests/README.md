# Tests

Open [unit/runner.html](./unit/runner.html) on the running static server for engine-level checks.

The unit runner verifies that generated no-drill routes complete through the movement and enemy simulation and reject a patrol collision.

The system runner replays all three approved photo fixtures across three fixed seeds to check route completion through real collisions, pickups, checkpoints, moving platforms, and patrols.

Open [system/runner.html](./system/runner.html) on the running static server for root-entry and workflow checks.

Review [acceptance/test-cases.md](./acceptance/test-cases.md) for the manual product acceptance scenarios.

The test pages require no package installation or build step.
